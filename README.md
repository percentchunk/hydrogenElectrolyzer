# Compact Water Electrolysis Demonstrator

A compact, modular water electrolysis demonstrator inspired by the small “arc reactor” aesthetic.

The project is built around a transparent cylindrical chamber, removable internal electrode cartridge, external structural tie rods, dedicated fill/drain and vent ports, and a custom upright PLA stand.

The main mechanical design was created in Onshape and has already been validated with a full-size 3D-printed fit prototype. The printed model confirmed that the core geometry, cap alignment, stand fit, cartridge clearance, and overall proportions work as intended.

## Current Status

- Full-size PLA fit prototype printed
- Stand fit validated

- Hardware sourcing and BOM planning in progress
- Cosmetic arc-reactor shell and lighting planned for later
